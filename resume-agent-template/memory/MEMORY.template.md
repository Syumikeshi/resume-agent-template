# MEMORY.template.md —— 项目状态快照（唯一真相源）

> **使用方法**：新用户的标准路径是由 Agent 按 `templates/onboarding.md` 的冷启动访谈协议
> 逐节生成；手动使用则复制本文件为 `memory/MEMORY.md` 再逐节填写。
> 删掉所有 `<>` 占位符与斜体说明。没问完/没填的节保留 `⏳ 待访谈` 标记，下次继续。
> 之后**每轮对话结束都更新它**（覆盖式更新，这就是快照的含义）。
> 结构可以按需增删节，但「档案 / 约束 / 交付物 / 当前待办 / 权威数字」五节建议保留。
