# onboarding.md —— 冷启动访谈协议（从 0 建立用户画像）

> **给 Agent 的执行协议。** 触发时机：`memory/MEMORY.md` 不存在（新用户第一次开工）。
> 目标：通过一场结构化问答，把用户画像建得**尽可能详细且每条有出处**，直接落盘为
> `memory/MEMORY.md` 的 §1–§4 + `memory/claim-source-map.md` 初版。
> 全程参考 `memory/MEMORY.template.md` 的节结构，问一模块填一节。

---

## 访谈总原则（先内化再开口）

1. **一次只问一个模块。** 模块内先抛 1 个开放式大问题让用户自由讲，再针对细节追问。
   不要一次列十个问题轰炸用户。
2. **先开放，后收敛。** 每个模块都是「自由叙述 → 具体追问 → 复述确认」三拍。
3. **数字必追出处。** 用户说"日均 200 条"→ 问"是有记录还是估算？"；
   说"提升很多"→ 问"大概百分之多少？怎么知道的？"
4. **不引导、不美化。** 不暗示答案（"是不是提升了 30%？"✕）；
   不替用户润色经历。用户怎么说就怎么记，措辞可以整理，事实不能加工。
5. **允许跳过。** 用户答不上来就记「待补」，访谈后进 MEMORY.md §6 待办，不逼问。
6. **证据分级即时标注**：`[证实]`（有书面材料）/ `[口述]`（用户口头说）/ `[存疑]`（猜测，不得上简历）。
   分级写进 claim-source-map.md 的「可信度」列。
7. **每个模块结束必须复述**："我来确认一下记下的——…"，用户点头才进下一模块。
8. **可中断可恢复。** 访谈随时可停；已完成的节正常填写，没问到的节标题下写 `⏳ 待访谈`
   并在 §6 记待办。下次会话从第一个 ⏳ 继续。
9. **访谈中用户提到的材料**（成绩单、证书、旧简历、JD），当场请用户放进 `input/`；
   用户直接粘贴内容的，征得同意后存 `input/interview-notes-<日期>.md`。

## 模块题库

### M0 · 开场与基本盘（5 分钟）

开场白先讲清楚："接下来我会分几个模块问你，一次一个主题，你随时可以说跳过或停下。"

1. 怎么称呼你？简历上用中文名、英文名还是两者都要？
2. 届别和毕业时间线？（哪年入学、哪年毕业、是否在读、能否实习/何时可入职）
3. 现在在哪个城市？租房/搬迁灵活性如何？
4. 简历上放哪个电话和邮箱？（这会成为 MEMORY.md §2 的联系方式权威值）
5. 手上有没有现成简历或领英主页？（**有 → 先请放 `input/`**；有现成简历时 M1/M2 可改为
   "对着旧简历逐条核实+补细节"模式，效率更高）

### M1 · 教育档案（每段学历一套）

对每段学历（本科/硕士/博士/交换，从最近往回）：

1. 学校、专业、学位、起止年月？
2. GPA 或排名？口径是什么（4.0 制/百分制/排名前 X%）？成绩单能放 `input/` 吗？
3. 奖学金和荣誉？（名称、年份、级别、覆盖率如"前 5%"）
4. 和目标岗位最相关的 5–8 门课程？
5. 有没有辅修、交换、海外经历、在线证书（Coursera 等）？

### M2 · 经历深挖（访谈的核心，时间花在这）

第一问（开放）：**"把你做过的事都倒出来——实习、兼职、项目、科研、社团、
比赛、创业、自媒体，只要有过实际产出的都算，先不挑重要的。"**

然后对**每一段**经历用同一套五问：

1. **背景**：什么组织/团队？什么角色？什么时间段？团队/业务规模多大？
2. **任务**：你具体负责哪一块？（划清边界：哪些是你亲手做的，哪些是团队的）
3. **动作**：你用了什么方法/工具？做过什么关键判断或决策？
4. **结果**：有没有数字——规模、时长、百分比、金额、人数、评分？（每个数字追问出处）
5. **证据**：留下了什么可查的产出——报告、代码、链接、截图、邮件、好评？

追问技巧：
- 用户说"参与了 XX 项目" → "你亲手做的是哪一部分？"
- 用户给不出数字 → "当时大概什么量级？拍脑袋估一个也行，我标成估算。"
- 同类经历多段 → 问清哪段最能打，哪段可合并/舍弃

### M3 · 技能与语言

1. 工具/语言/框架清单，逐个自评：熟练（能独立交付）/ 会用（做过）/ 了解（学过没实战）？
2. 语言能力：英语（有无成绩：四六级/雅思/托福）、其他语言及等级？
3. 职业证书？
4. **技能挂经历**：每个"熟练"问一句"在哪个项目里用过？"——挂不上任何经历的技能降级为"会用"。

### M4 · 求职约束（红线，全部进 MEMORY.md §3）

1. 薪资底线？口径说清：月薪/年薪、几薪、税前税后？可接受面议吗？
2. 地点：可接受城市按优先级排？绝对不去哪？
3. WLB：加班底线（接受 965/大小周/ occasional 加班？）、出差接受度？
4. 排除项：行业、岗位性质（如纯销售）、公司类型（如创业公司/外企/国企偏好）？
5. 其他硬约束：家庭因素、健康、签证、考试时间窗？

### M5 · 方向探索（产出 MEMORY.md §4）

1. 你现在心里想投什么方向？为什么是你？
2. 有没有明确的 target 公司或具体 JD？（有 → 存 `input/jd-<公司>.md`）
3. 有没有"明确不想做"的方向？
4. 然后由 **Agent 基于档案发言**：结合 M1–M4 给出 2–4 个候选方向，每个附
   匹配理由（引用刚才访谈里的具体经历）和风险提示；**用户拍板**选 1–4 个。
5. 每个定下的方向：目标岗位类型名称 + 该方向简历要突出的 3 个关键词。

### M6 · 现有资产与进度

1. 已经投过哪些公司？有没有进行中的流程（笔试/面试中）？（避免重复投，进 §6）
2. 内推资源、校友、社群人脉？
3. 已有的其他材料：作品集、个人网站、GitHub、公众号？

### M7 · 时间线（产出 MEMORY.md §9 雏形）

1. 打算什么时候开始投？
2. 期望什么时间拿到 offer / 最晚什么时候必须上岸？
3. 已知的硬截止日期（网申截止、毕业手续、考试）？

## 收尾（访谈结束时 Agent 必做）

1. **画像复述**：用 5–8 句话把用户画像讲回去（谁、会什么、要什么、红线是什么），
   用户确认"就是这样"才算完成。
2. **落盘清单**：
   - `memory/MEMORY.md` §1–§4、§9 填好（含联系方式与权威数字）；没问到的节写 `⏳ 待访谈`
   - `memory/claim-source-map.md` 建好初版（本轮挖到的每个关键数字登记一行）
   - 材料缺口列进 §6 待办（如"缺成绩单 → 请放 input/"）
3. **建议下一步**：按 AGENTS.md §2 工作流，下一站通常是「做简历」（工作流 ④）或先补材料。
4. 本轮对话按收尾清单（AGENTS.md §8）走一遍——这是第 1 轮，commit message 建议
   `第 1 轮：冷启动访谈，建立用户画像`。
