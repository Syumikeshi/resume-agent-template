# claim-source-map.template.md —— 断言出处对照表

> 复制为 `memory/claim-source-map.md`。简历里每个**关键断言**（数字、头衔、
> 时长、成果）登记一行。目的：任何一条被质疑时，30 秒内找到出处；出处不支持时，
> 沿「影响交付物」列全局排查修正（修正不会自动传播）。
>
> 「可信度」三档：**证实**（有书面出处）/ **口述**（用户口头确认）/ **存疑**（待核实，不得上简历）。

| 断言（简历上的写法） | 出处文件 / 对话 | 原文摘录或确认内容 | 可信度 | 处理决定 | 影响交付物 |
|---|---|---|---|---|---|
| GPA 3.6 / 4.0 | input/成绩单.pdf | 成绩单第 1 页 Cumulative GPA: 3.6 | 证实 | 直接使用 | example-zh.tex、example-en.tex |
| A/B 测试转化率 +1.8pp | 与用户确认（第 3 轮） | 用户口述实验结果 | 口述 | 保留，但需先拿到书面出处才写进简历 | example-zh.tex |
| <示例行，使用时删除> | | | | | |

## 使用纪律

1. 新断言进简历**之前**先登记，再写进 tex
2. 出处变化（成绩单更新、口径修正）→ 改「权威值」，再按「影响交付物」列逐一排查
3. 任何需要为简历内容负责的场合之前（面试、背景核查），把对应简历的断言全部过一遍本表——这是诚信红线，也是自信的来源
