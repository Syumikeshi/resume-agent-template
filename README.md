# Resume Agent Template · 从 0 写简历的工作区

> 下载 → 放进素材 → 在 AI Agent（Claude Code / Cursor / ZCode / Codex / Gemini CLI…）里打开，说一句「读 AGENTS.md 开始」——它会陪你走完**从 0 写简历 → 熟悉自己的简历**的主线，并附上投递记录工具。面试辅助刻意不在范围内：需要模拟面试请用专门的面试项目，本项目的产出可直接作为它们的输入。

**English introduction: [README.en.md](README.en.md)**

## 这是什么

一个把「写简历」当**工程项目**来管理的工作区模板。它不只是简历模板文件，而是一套经过 60+ 轮真实求职打磨的**方法论 + 工具链 + Agent 操作手册**：

| 你要做的事 | 工作区怎么帮你 |
|---|---|
| 建立画像 | 冷启动访谈协议：八模块问答把你的经历问透，每个数字带出处 |
| 写简历 | ATS 友好的 LaTeX 模板（中/英 × 彩色/黑白，一个命令全编译）+ 防编造的「断言出处对照」纪律 |
| 熟悉简历 | 断言过堂 / 口述对照 / 弱项清单——让每一条你都能亲口讲清、拿得出出处 |
| 记录投递 | 梯队制清单（markdown）→ xlsx 追踪表（下拉/着色；**增量更新，重跑不丢手填数据**） |
| 管理状态 | 四层文档模型：MEMORY.md 一份文件交接全部状态，会话日志只追加 |

## 快速开始

**第 1 步 · 拿到本地**

```bash
git clone https://github.com/<你的用户名>/resume-agent-template.git
cd resume-agent-template
```

（自己用建议先删掉 `.git` 重新 `git init`，让历史从你的项目开始。）

**第 2 步 · 放素材**

把你的原始材料放进 `input/`：现有简历（任何格式）、成绩单、证书、想投的 JD……至少放一份初版简历（参考 `input/initial-resume.template.md` 的格式）。

**第 3 步 · 打开 Agent，开工**

用 Claude Code / Cursor / ZCode 等打开这个目录，说：

```
读 AGENTS.md，然后帮我开始
```

Agent 会先做一轮**冷启动访谈**（协议在 `templates/onboarding.md`）：分八个模块把你问透——
基本盘、教育、**经历深挖**（每段经历五问：背景/任务/动作/结果/证据，数字必追出处）、
技能、求职红线、方向探索、现有资产、时间线——边问边落盘成你的 `memory/MEMORY.md` 画像，
然后按工作流陪你逐步推进。随时可以停下，下次从没问完的模块继续。

**第 4 步（可选）· 环境依赖**

- 编译简历：[TeX Live](https://tug.org/texlive/) / MacTeX（含 XeLaTeX）+ poppler（`pdfinfo`/`pdftotext`，用于体检）
- 追踪表：Python 3.9+（openpyxl 缺了会自动装）
- 字体已做回退链：macOS 用原生字体，Linux/Windows 自动落到 TeX Live 自带字体

└── templates/         冷启动访谈协议 / 熟悉简历协议 / 断言出处对照表 / CHANGELOG / 会话记录模板

## 三分钟理解方法论

1. **四层文档模型**：入口 README（是什么）→ 指针（在哪）→ 快照 MEMORY.md（现在怎样，可覆盖）→ 流水日志（怎么变的，只追加）。开新对话只需 MEMORY.md 一份就能交接。
2. **一轮一提交**：每轮 AI 对话结束时提交一次 git（`第 N 轮：<主题>`），日志五块结构（诉求/结论/改动/待决策/下一步），里程碑打 tag。
3. **清单是唯一真相源**：想投哪些公司写在 markdown 清单里，追踪表由脚本派生——**增量更新，重跑不丢手填的投递日期/进展**，改清单重跑即可同步。
4. **诚信纪律**：简历上每条关键断言登记出处；不编造、不美化数字；发现错误全局排查引用。
5. **五项简历体检**：页数 / Overfull hbox / 文本层可提取 / PDF 元数据 / 黑白脱色——详见 `docs/lessons.md`。
6. **主线终点是熟悉简历**：断言过堂 + 口述对照。模拟面试等面试辅助请用专门项目——本项目的简历、出处对照表、熟悉记录可直接作为它们的输入。

## 给 Agent 用户的提示

- 本仓库**不含任何真实个人信息**，放心 fork；你放进去的数据（input/、memory/）是你的，注意别把私人仓库公开
- 想改简历版式 → `resume-src/common/*.cls`；想加求职方向 → 复制 example 的 tex 改名，再在 `build.sh` 的 `TRACKS` 里登记
- 需要**模拟面试 / 面试辅导**？本项目刻意不做——请使用专门的面试辅助项目，把这里的定稿简历、断言出处对照表、熟悉记录直接作为输入
- 详细工作法（页边距测量、依赖传播审计、删减优先级等）在 `docs/methodology.md`
