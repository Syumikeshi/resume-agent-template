# input/ —— 你的原始素材

把你手上所有**原始材料**放进这个目录。Agent 只读不改动它们；一切交付物从这里的事实出发。

## 建议放什么

| 素材 | 说明 | 优先级 |
|---|---|---|
| 初版简历 | 你现有的简历，任何格式；没有就照 `initial-resume.template.md` 的结构口述一份 | ★ 必需 |
| 成绩单 | 扫描件或照片即可（GPA 等数字的权威出处） | 强烈建议 |
| 证书 / 奖项证明 | 语言成绩、职业证书、获奖文件名写清楚 | 有则放 |
| 目标 JD | 想投的岗位描述（存成 `jd-<公司>-<岗位>.md` 或截图） | 投递期放 |
| 作品 / 项目证明 | 论文、项目仓库链接、作品截图 | 有则放 |

## 命名建议

- 素材文件带日期：`成绩单-202609.pdf`（同名更新时能分清新旧）
- JD 统一前缀：`jd-xxx.md`

## ⚠️ 隐私提醒

这个目录会装你最敏感的个人信息（证件号、成绩、住址）。**你的求职仓库请保持私有**；
如果哪天要公开或分享，先清空 `input/`、`memory/`，并确认 git 历史里没有它们
（提交过的文件会永远留在历史里——必要时删库重建）。
